\section*{Executive Summary}
This report presents the results of the R-based analysis layer applied to the PostgreSQL warehouse core schema. The analysis covers customer tenure, revenue seasonality, fulfillment funnel, campaign lift, inventory health, pipeline health, and geographic splits.

\section{Methodology}
\subsection{Data Source}
All analysis queries read from the \texttt{core} schema in PostgreSQL via RPostgres.

\subsection{Analysis Approach}
- EDA profiling via Quarto notebooks
- Headless R scripts for batch analysis
- Statistical analysis using tidyverse, survival, and forecast packages
- Visualization via ggplot2 with consistent theme

\subsection{Dependencies}
R packages documented in \texttt{renv.lock}
