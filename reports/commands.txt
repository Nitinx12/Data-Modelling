# 6. Dashboard — Streamlit on core (local + Streamlit Cloud)
# See dashboard/README.md and docs/HOSTING.md for full guide.
# Local against Docker DBs (no Neon needed):
#   PowerShell: $env:POSTGRES_HOST="127.0.0.1"; $env:POSTGRES_PORT="5433"; $env:POSTGRES_DATABASE="data_warehouse"; $env:POSTGRES_USERNAME="user"; $env:POSTGRES_PASSWORD="password"
#   Then either:
make dashboard
#   or directly:
uv run streamlit run dashboard/Home.py
#   Opens http://localhost:8501 — uses env fallback (no secrets.toml needed for local Docker).

# Local against Neon/Supabase (cloud DB for deployed dashboard):
#   Copy example and fill with Neon creds (dashboard_reader, sslmode=require):
#   cp dashboard/.streamlit/secrets.toml.example dashboard/.streamlit/secrets.toml
#   # edit dashboard/.streamlit/secrets.toml [postgres] host/user/password from Neon dashboard
#   uv run streamlit run dashboard/Home.py
#   # Verify every page loads against Neon before deploying.

# One-time Neon setup (from local machine, after a local pipeline run):
#   pg_dump -h 127.0.0.1 -p 5433 -U user -d data_warehouse -n core --no-owner --no-privileges -f core_dump.sql
#   psql "$NEON_CONNECTION_STRING" -f core_dump.sql
#   psql "$NEON_CONNECTION_STRING" -c "CREATE ROLE dashboard_reader WITH LOGIN PASSWORD 'strong-password'; GRANT USAGE ON SCHEMA core TO dashboard_reader; GRANT SELECT ON ALL TABLES IN SCHEMA core TO dashboard_reader; ALTER DEFAULT PRIVILEGES IN SCHEMA core GRANT SELECT ON TABLES TO dashboard_reader;"

# Deploy on Streamlit Community Cloud:
#   1. Push dashboard/ to GitHub (ensure dashboard/.streamlit/secrets.toml is gitignored — already in .gitignore:154)
#   2. https://share.streamlit.io → New app → repo/branch → Main file path: dashboard/Home.py
#   3. Advanced settings → Secrets → paste [postgres] TOML (same as local secrets.toml, dashboard_reader)
#   4. Deploy → https://your-app-name.streamlit.app — click through every page (Fulfillment, Sales, Marketing, Inventory, Health)
#   5. Add live link to README.md top (already placeholder: README.md:12) next to CI badge
